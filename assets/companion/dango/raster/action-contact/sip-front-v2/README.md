Rebuild into a fresh directory:

    python scripts/rebuild.py --repo-root /path/to/bubu --output /new/output/path

External canonical references are resolved via repo-relative paths and hashes. Historical absolute original-generation paths in metadata are evidence only and are never read by rebuild.
