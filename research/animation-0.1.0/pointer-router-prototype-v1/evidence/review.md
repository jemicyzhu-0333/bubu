# Independent shared pointer-router functional review

Result: functional boundary review passed for the source hashes in source-sha256.txt. This is a fake EventTarget/capture/scheduler integration test with the actual admitted full18 actor, real Three Raycaster, original face owner and real body adapter. It is not a browser, WebGL, OS pointer-capture, performance, or artistic approval.

Independently executed: all 17 final pointer tests passed, including combined blur/visibility blocking and bounded input rejection (tests-final-17.log). Earlier 15/16-test runs are retained separately. Final coordinate-bound guard also passed two targeted tests (final-guard-tests.log). Additional independent probes compare same-time versus separate-frame move/release placement, revoke qualification after camera-induced pending contact loss, and sustain a one-hour foreground frame gap without output overflow. Exact outputs are in independent-probes.log.

Review found and implementation repaired:
- Same-time final move was lost before release recorded landing height/location.
- Finite pointerup coordinates were ignored.
- Pending contact loss was checked after qualification and incorrectly generated R0.
- Large visible frame gaps overflowed the pure petting output queue and could stop RAF scheduling.
- Lifecycle barriers left the externally observable state snapshot stale.

Current design maintains one admitted actor, one face owner and one router body writer; internally raycasts against the owned skin, without accepting caller eligibility/hit claims. Tests cover pointer identity and button ownership, capture acquisition/release failures, cancel/lostcapture/blur/visibility/disposal, equal-time batching, late-event rejection/terminal retirement, petting-to-drag transition, CSS rectangle/DPR separation, surface-loss qualification, and cleanup.

Boundaries: HTML workbench has not been browser-executed. Capture exceptions prove internal cleanup, not actual OS capture behavior. Late terminal input intentionally retires safely instead of animating an obsolete drop. New down during landing is intentionally ignored. Fixed-pointer petting IK, arbitrary CSS transforms/iframes, original art amplitude, and blush/mouth candidates remain outside this signoff.
