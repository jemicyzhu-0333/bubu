#18-slot static expression library preview candidate

This is a compact catalog and reproducible visual overview, not a merged runtime asset. It contains actual3D endpoint render inputs, fixed-scale front previews, provenance and per-state asset/target hashes. No AI-generated image stands in for a model frame.

Run `python rebuild_previews.py` with Python, numpy and Pillow to rebuild the boards from the18 local render inputs. No model download or Blender installation is needed for the preview itself. Original complete model/rebuild packages are separately archived as approved-assets and expression-assets/basic-batch1..5-candidate. To independently recheck common bases and every current knot hash against those packages, set BUBU_ARCHIVE_ROOT to the checkout folder research/animation-0.1.0 and run python verify_catalog_sources.py; its result is written under _verification without changing this manifest.

Current approval status is recorded per face. Four r6 expressions01/04/07/08 remain approved and exact; batch1 D1/N2/P2 received positive actual3D feedback. Other actual3D batches are candidates awaiting the user's confirmation. Reference selection and internal static checks are not substituted for that confirmation.

R0 is an independent short-horizontal neutral variant; the original O-mouth Basis has not changed. T05 is the newly revised mild-unease face. T5 is closed-eye sadness. Historical r6 Face05 is retained only in source history and is not included among these18 current slots.

The18 slots do not mean18 unrelated emotions. D1/A4 are neighboring low-lid states distinguished partly by brows. P2/A7 use similar closed-eye families but differ in the mouth. T5/S5 are closed/open states of sadness. D4 is a yawn transition, not an indefinitely held idle. Convincing shyness and an independently selected half-awake design remain gaps.

The catalog verifies common base geometry, topology, weights and normals across all source packages. Future banking should store the body once and preserve all authored POSITION/NORMAL knots and sparse zero-base semantics. Gaze is not implemented. Direct cross-face mixing, dynamic timing, dragging and petting remain outside this static candidate gate.
