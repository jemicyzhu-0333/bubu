# Art adapter gate — not an active profile

This document is not a loadable runtime pack. The first slice deliberately accepts only `purpose: mechanics-fixture`.

The approved 05 shape and r4 rig are reference evidence. r6's selected shapes 01/04/05/07/08 have a historical approval record; expression 05 has since been reopened and is currently revision_pending. The other selected shapes remain reference evidence; this does not approve the unfinished complete expression library or activate an interaction. A shape ID, its semantic reading, and its verified runtime use are three distinct facts. In particular, 01 must not be automatically treated as `surprise` because an older controller used that name; its current dominant reading is curiosity and semantic use needs review.

For a future adapter, declare each item independently:

| Capability | Engine support now | Current art binding | Verified scope |
| --- | --- | --- | --- |
| Joint delta rotation | Implemented on fixture | r4 rest/axes/caps exist as source evidence | Fixture runtime only; old art evidence is not new-engine acceptance |
| Single expression path | Implemented on fixture | r6 sampled path exists, not loaded here | Fixture knots/neutral bridge only |
| Face semantic template | Mechanical test IDs only | New five expression groups still being reviewed | No new semantic behavior approval |
| Independent gaze | Unsupported | Not implemented | None |
| Brows | Unsupported | New design layer pending | None |
| Knee/neck/wrist synthesis | Unsupported | These joints do not exist in r4 | None |
| Rigid attachment | Implemented on fitted fixture | AccessoryAnchor source exists; real fit not supplied | Fixture transform inheritance only |
| Garment skin / cloth collision | Unsupported | No new-engine binding | None |
| Ground / surface-grab solver | Unsupported in new engine | Old05 is evidence, not imported code | None in 0.1.0 foundation |

A future face adapter must preserve the fixed body-local coordinate chart, include both eyes/highlights/mouth, map approved per-path intensity curves and prove exact neutral. Eye shape, eye orientation/gaze and highlight attachment should be separate declared layers. An absent layer remains unsupported; a highlight must never silently stand in for a pupil. New brows need a separate bounded layer and explicit ownership.

Direct r6 cross-face overlap is forbidden. The fixture's single-path machinery does not certify r6's geometry, represent all 20 candidate expressions, or approve any proposed timing. Single-primitive/POSITION-only morph/target-count restrictions also mean this loader is not presently a drop-in r6 loader. Add an art adapter only after the complete basic expression library is approved and archived, then run new asset-binding, sampled-shape, multiview and event-time checks.

Latest art status: a separate short-horizontal neutral variant and new bounded brow/inner-mouth layers are candidates only. Archived Basis is unchanged. Candidate files do not authorize a new binding; independent gaze remains unimplemented.
