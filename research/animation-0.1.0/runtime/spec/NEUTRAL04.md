# Neutral-only art compatibility contract

New explicit purpose: approved-art-neutral. Only fixed approved static05 and historical selected-faces r6 hashes may enter. This is a readiness/load diagnostic, not a complete art library or motion approval. All morph weights stay zero; no play/clip/face/input API is exposed. Existing mechanics mode remains distinct and unchanged.

Asset allowlist:
- static05:3b7adcb303c8bd3c0dfb8976f9eb8fc0e6cefb897a7c16e99acc827385591722
- r6:fba41db41ecb0e0a959cd6923f55d5edbfaebf4558d79e1e9832b2a806cc5830

A dedicated art preflight validates the self-contained GLB before GLTFLoader. Allow only KHR_materials_specular and KHR_materials_ior with their numeric untextured fields; COLOR_0 float3/float4; POSITION/NORMAL morphs; known bounded provenance extras on the root/body/face nodes and HeadTouch.surface_normal_blender (inert data, never capability declarations). Unknown extensions/fields, external resources, textures, animations and unsupported vertex channels still reject. Sparse decoding validates cumulative work before allocation, ordered indices, value/base ranges and zero base when absent. No blanket extension pass-through or limits expansion of mechanics mode.

Neutral hard ceilings:12MiB asset,16MiB pack source bytes,1MiB GLB JSON,32nodes,8meshes/materials,1primitive/mesh,60kvertices,300kindices,64morph targets/mesh,768accessors/views,4M accessor scalars,400kmorph-expanded vertices. Manifest declarations may lower ceilings; approved exact hashes and actual binding checks remain mandatory. General runtime ActorPool hard maxima are not increased by this scope.

Binding: exact unique names/mesh roster; declared static versus skinned role; actual node transforms/rest pose; complete eyes/highlights/mouth roster, source rig/skin identity. No knee/neck/gaze synthesis. Keep full source arrays and material extensions. Runtime normalized WEIGHTS_0 is an explicit Three transformation: compare with independently normalized source, not a blanket byte-equality claim. Source/base data stays immutable.

Resource policy: first version parses the full approved asset in read-only neutral form, with measurable decoded arrays and cleanup. Face-bank residency/caching is not introduced. Multiple actors may share immutable geometry/material templates and own their skin state. Static actors have demand redraw on explicit invalidation/context restoration, no continuous animation clock. Post-dispose/unsupported API calls reject; pending creation cancellation and all reservations roll back.

Verification: real hash-locked static05/r6 load, source vs decoded base arrays and normalized weights, morph all-zero invariant, full semantic roster, material fields, typed-array budgets, negative sparse/extension/profile/hash cases, duplicate/dispose/cancel ownership, CPU load/clone/resource measurements. WebGL appearance, GPU allocation, browser context restoration and final long-press/drag remain unverified/gated.

## Implemented API and ownership

`prepareNeutralPack(reader, {signal})` owns each byte snapshot before awaiting hashing, validates the exact registered GLB hash, applies art preflight, validates a complete profile and returns frozen metadata plus copy-on-read bytes. Profile JSON cannot approve a different source. Source provenance extras are bounded inert strings/numbers, not interpreted behavior. Current registration is strictly two historical approved neutral sources. r6's old face05 design has since been superseded for new facial work; all of its faces remain inactive here.

The same `ActorPool.create(pack, {signal})` dispatches the neutral adapter. Its reservation covers pending and active mechanical and neutral actors together. The new pool field `decodedArrayBytes` is a conservative reservation for shared geometry attribute/index/morph backing, default64MiB/hard256MiB. It is deduplicated by the same versioned source-cache identity as encoded bytes, retained through late cancellation and released only when the cached parse is gone. The reservation per GLB is encoded asset bytes + all fully expanded source accessor bytes; the actual parsed geometry backing must fit it. Clip JSON contributes0 to this geometry field. Neutral pack declarations can lower a16MiB per-source ceiling, never increase it. This reservation excludes parsed-source copies, JS objects/cache metadata, caller-owned prepared packs, temporary comparison arrays, per-actor skeleton state, renderer morph staging/textures, driver resources and VRAM. It is not a complete resident-memory ceiling.

`createNeutralSuite` is an adapter entry used by ActorPool, not a second global admission domain. The application must route every actor through its one pool. Returned actor methods are `assertNeutral`, static `advance`, `isAnimating`, `nextDeadline`, and idempotent `dispose`; there is no enqueue, clip, face, gaze or interaction entry. `advance` is a static no-op with finite nonnegative time validation. DemandLoop redraws only when invalidated. Camera changes do not change actor yaw/rest. ContextLifecycle's simulated loss/restore policy can request a redraw, but cannot prove driver restoration.

A parsed source is validated once per cache lifetime. Every clone is then checked for source rest TRS, hierarchy and zero morphs. All node names are unique in preflight. Complete six-mesh body/face and seven-joint rig roles are bound. Every used POSITION/NORMAL/COLOR/JOINTS/WEIGHTS/index/morph array is compared numerically with independently decoded source values. This is numeric equality (`+0` and `-0` are equal), not a bytewise geometry proof. WEIGHTS_0 is first normalized exactly as pinned Three's `SkinnedMesh.normalizeSkinWeights`; r6 changes25 scalars by at most5.960464477539063e-8. All other compared values are unchanged. Material vertex-color enablement/color/roughness/metalness/opacity/side/specular/ior and inverse bind matrices are checked. No normal recomputation, shape conversion, endpoint-only approximation or asset rewriting occurs.

The public `root` is a trusted-host scene handle. Geometry/material templates are shared and must not be mutated. Actor skin matrices/morph influence arrays are independent. `assertNeutral()` detects pose/morph changes when explicitly called; there is no per-frame full-mesh guard and no security promise against host code intentionally mutating scene objects. Failed, aborted and disposed creation releases clones and source leases. Geometry/material/skeleton resources are disposed through the existing ownership rules.

## CPU and portable verification

Both exact GLBs are bundled under `fixtures/neutral-static05` and `fixtures/neutral-r6`; required tests never skip because of an external workspace path. `tools/build-neutral-packs.py <archive-root>` is an optional repackage tool and checks original SHA256 before copying without conversion. All normal tests work from this package alone.

`node tools/benchmark-neutral.mjs [output.json]` measures both real packs at1/4 actors with1warmup+5 measured runs. It separates standalone preflight, complete prepare including file/hash/binding, cold create including GLTFLoader+numeric parity+clone, remaining cached clones, and group disposal. The10000 static advance calls per actor are explicitly no-op CPU calls, not render or deformation workload. Hashes before/after, raw samples, environment and zero ownership checks are included. CPU timings cannot establish GPU performance or visual fidelity.

`neutral.html` is a runnable optional browser diagnostic with static05/r6 loading, camera controls and disposal only. No WebGL execution or screenshots are claimed by this checkpoint. The permitted cloud browser route remains blocked; user computer access and security workarounds were not used.
