# Historical approved neutral source

This pack preserves its source GLB bytes and SHA256. It is registered for neutral rest loading only in the 0.1.0 adapter. Every morph remains zero and there is no expression/motion API. The historical r6 face05 shape is no longer the current design direction. New face-library candidates are not part of this pack.

Run the package tests without regenerating these files. Optional archive regeneration: `python3 tools/build-neutral-packs.py <source-archive-root>`.
