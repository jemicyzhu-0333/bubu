# Art adapter and readiness boundaries

The 18 current static facial slots were approved on 2026-10-17. Original body/Basis is unchanged. Shape-source approval, intended semantic reading and verified runtime behavior remain three separate facts. Historical r6 face05 is preserved in old archives and superseded by T05; it must not become the new runtime's fast-drag face by name alone.

| Capability | Engine scope | Actual binding | Evidence boundary |
| --- | --- | --- | --- |
| Neutral source loading | Implemented in checkpoint04 | Fixed static05/r6 hashes | CPU numeric/rest/material parity; WebGL appearance unverified |
| Single semantic face | New checkpoint05 candidate | Seven fixed current slots, complete8face layers | Source-array proof, bounded clock and actual transition visual gate remain separate |
| Authored brow/tongue shapes | Part of the same face path | N2 brows, N3 inner tongue, explicit hidden Basis | No independent layer controls; all layers reset on every path |
| Joint delta / authored quaternion clips | Mechanical fixture | Real r4 axes/rest are reference data only | No new-engine art motion acceptance |
| Independent gaze / brows | Unsupported | No bounded independent channels | Highlights are not gaze controls |
| Knee/neck/wrist synthesis | Unsupported | Anatomy absent in r4 | No silent fallback |
| Rigid accessories | Fitted mechanical fixture | Real fit still required | Transform inheritance is not collision |
| Garments / cloth / prop contacts | Unsupported | No real adapter | No collision guarantee |
| Surface grab / landing | Not integrated in0.1.0 | Old05 archives are evidence only | New continuous solver and visual gate required |

The expression adapter is a separate purpose, not an expansion of neutral-only readiness. It starts at original small-O Basis. R0 is a full-intensity semantic short-horizontal face and is not implicitly activated. Every active path includes both eyes, both highlights, mouth, both brows and tongue; absent source layers are explicit zero deltas. The body remains one shared unmorphed mesh.

Exact source arrays, authored POSITION/NORMAL knots, COLOR/materials and allowed zero-area closed/hidden layers are preserved. Parser limits are calibrated to the seven-slot subset. The master18 source exceeds that purpose's registered hash/target limit and is not silently admitted. Full-library or bank-residency activation is a later bounded decision with real renderer evidence.

Only one semantic face path can be active; adjacent knots of that same path may both be weighted. No direct dual-face blend is approved. A scalar clock's C1 property does not make a piecewise geometric path C1; actual99px imagery must inspect shared-Basis crossings, rapid re-entry, N3 tongue emergence and readable arrival holds. Explicitly returning through Basis can itself create an unwanted small-O mouth/eye flash, which remains an artistic gate rather than a numerical failure.

Genuine WebGL rendering, browser input latency, native/Electron behavior, current-library drag and long-press interaction are not established by the source, CPU or offline Blender checks. See FACEPATH05.md and ART-TRANSITION-NEXT-GATE.md.
