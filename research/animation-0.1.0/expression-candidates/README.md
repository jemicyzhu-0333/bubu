# Five-group facial design references: awaiting user approval

This is a compact reference-design snapshot, not a final basic-expression asset library. The user approved continuing the five-group design exploration; the twelve displayed new/prior-unapproved references are awaiting selection. Six displayed images directly quote approved neutral05/r6; they are not regenerated. No GLB or runtime is changed here.

## Included
- Final master of each of five groups, exact original prompts and targeted-repair prompts. Earlier intermediate generated masters are intentionally omitted; prompt history records the design request, not a deterministic promise to rerun image generation.
- Prior A master for A4/A7/A8 candidate crops, six approved actual r6 reference renders, explicit source partitions, final two review boards, cross-group dedupe boards and review limitations.
- `selection-and-crop-spec.json` maps every shown ID to retained source pixels and proposed reading. `compose_recommended.py` rebuilds the two review boards using Pillow/numpy and Noto Sans CJK (Regular/Bold); all inputs are included locally. It does not edit facial pixels.

The actual99px board fixes body silhouette height to99pixels. Semantics remain proposed readings. D4 is a yawn passage, D3 awake-drowsy remains unresolved, and shy is still missing. Request requires target/acting. T5/S5 are closed/open setback states. New eyebrows and gaze require a future separate3D contract and visual gate. Generated body micro-drift must never replace approved05 geometry.

No video, superseded first-pass master, production mesh, credential or private source is included. Gold model archives remain separate.
