# 02 · milestone.sunhat · 小草帽（露耳小软帽）

The user approved the redesigned miniature ear-exposed concept on 2026-10-17. This actual-model candidate replaces the rejected large head-covering hat. It follows the approved concept, not the old full-head fit. Final actual-model visual acceptance is separate from concept approval.

## Design and immutable body
A miniature hollow straw hat rests in the central valley between the original pink ear peaks. Narrow softly waved brim, low rounded crown, modest cocoa ribbon, 5° sideways and 4° fore/aft tilt. Both pink ears remain outside the hat. No body flattening, hidden ear geometry, new head, face or limb edits. All renders import the approved D2 GLB SHA256 84ec5d8608f21e43bf06df26b8b2f81124909ebb39c77bb9cc153aca17319a3a.

Crown outer radii .215/.205, height .225, shell .012. Brim radii .32/.27, nominal total thickness .018, gently waved/rolled outline with smooth upper-height limiting to preserve the ear tips. Placement translation is (0,.025,1.695) in Blender body coordinates before export anchor subtraction. The brim is genuinely hollow/open below. The inner brim and lower crown conform to the unchanged D2 scalp via downward BVH sampling with a small contact clearance, fading to zero deformation before the outer edge/upper crown; this removes the visible rear floating gap without lowering the whole hat. Embedded 256px woven-color texture is generated by source, not strand geometry.

The current approved generated design and prompt are references/generated-worn-and-turnaround.png and references/prompt.txt. Older rejected checkpoints are history, not current validation.

## Fresh checks on this geometry
- Actual mesh fit in both directions: hat vertices against unchanged skin, and head vertices against closed hat material volumes. A .002 contact tolerance is explicit; minimum distance and signed contact depth are recorded. The old “all 8705 head vertices inside a large ellipsoid” test is removed and is not applicable.
- Ear diagnostics cover 8 yaws × 3 elevations, reporting full visible ear surface, sampled upper contour, and z>1.76 tip-region visibility separately. Front, both front/rear quarter views, and back at level camera must preserve all body-visible tip-region vertices. Strict side views naturally merge the two ears in projection; some far-ear inner surface/tip vertices can be hidden by the foreground hat. The report does not claim all ear surfaces are visible from all cameras. Actual strict side and both quarter renders accompany the data.
- 18 endpoint faces × 5 yaws × 3 elevations: 270 cases with eyes, brows, highlights, mouth and tongue. Body-hidden/degenerate feature vertices excluded. Actual final GLB rays, plus current geometry-derived vertical clearance audit.
- Real weighted D2 ActorPool + finite four-bone BodyRigAdapter, 241 frames. Anchor, actor invariants, cleanup and second-actor isolation. Another 361 updates test shared immutable geometry/material/texture, private transform trees, reduced-motion operation and zero shared-resource disposal.
- Closed manifold topology after audit-only seam welding. Five worn views, five isolated views, underside, 12-view 360 sweep, eight bounded pose fixtures and four expression pairs. These are actual GLB renders, not generated character pixels.

## Runtime contract
SunhatAdapter imports ../01-sprout/src/sprout-adapter.mjs relative to this item directory. Attach outside the validated actor subtree under BodyRigAdapter.offset. Update after body pose with host time. Loader owns shared geometry/material/texture until the last adapter is disposed. Adapter removes only its own transform tree. The wardrobe owner handles headwear exclusion; there is no production selector/resource-manager integration here.

Node uses an explicitly labeled metadata-only texture hook; it verifies embedded bytes, not pixel decoding. Blender renders decode the real embedded PNG. No WebGL/native window or pointer-event execution is claimed.

## Reproduce
From research/animation-0.1.0/accessories-v1/02-sunhat, restore sibling 01-sprout, shared runtime D2 fixture, and Three.js 0.186.1 in animation-0.1.0/node_modules.

blender -b -t 2 --python-exit-code 1 --python src/build_sunhat.py
blender -b -t 2 --python-exit-code 1 --python src/audit_mesh.py
node src/test-host.mjs
blender -b -t 2 --python-exit-code 1 --python src/render_sunhat.py
python src/compose_review.py
blender -b -t 2 --python-exit-code 1 --python src/audit_fit.py -- --body ../../runtime-facepath05/fixtures/face-d2/asset.glb

Default render body is the same relative D2 fixture. BUBU_RUNTIME_ROOT overrides the Node dependency root. Render --body/--look are optional overrides. All18 audits require explicit --body and --mapper <approved face_library.py>; render --mapper adds the expression regression images. Build also reads that D2 fixture for contact fitting; --body overrides it. No user's local machine or original workspace absolute paths are required. The PNG and published GLB are checksum-locked; rebuild exports are not promised byte-identical.

## Limits
Discrete geometry/vertex tests and bounded poses are not every-pixel or continuous collision proofs. Future poses, face transitions, cameras, simultaneous headwear and production presentation require additional checks. Historical pre-fix-all18-hat-occlusion.json is retained only as rejected-old-design evidence, not as a current result.
