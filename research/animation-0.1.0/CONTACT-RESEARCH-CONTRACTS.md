# 研究接触/布料合同（自 ARCHITECTURE.md 迁出）

> 2026-11-03 从 `docs/ARCHITECTURE.md`「V2 动画研究底座」迁出，内容未改动。仅用于身份校验、失败复现与离线审计，不是在线运行前置。

## 历史研究合同与证据边界

以下研究实现和精确接触合同保留用于身份校验、失败复现和必要的离线审计；
其中全局高精度求解与连续数学证明不作为 G0/G1 的在线帧循环或启动前置。
实际可见接触、安全动作和资源所有权仍必须验收，并非通过取消研究前置降低门槛。

`research/animation-0.1.0/animation-foundation-v1` 目前是独立研究包，不写任何 canonical
持久化路径，不新增应用 IPC，也不修改已批准的身体、表情或装备模型。
`FoundationPool` 拥有角色集合、CPU 资源预算及共享原始肢体源的租约；
角色拥有单一输入/表情驱动、锚点、装备、动作和效果生命周期。
原始肢体几何可共享，角色 Skeleton 不共享；最后一个租约释放实际资源及对应预算。

接触准入按 actor source/parts、action trajectory/attachment、garment model/attachment
的精确哈希组合判断。记录由验证源码身份的组合层提供，请求不能自报兼容。
未知或仅通过端点采样的组合不能获得全动作准入；单件通过不外推为整套通过。
实际装备的接触身份还绑定完整规范化配置、实例挂点偏移、次级运动限制及独立
动画轨道快照。异步身份计算与加载共用换装的代次和资源预留；旧证据不能沿用到
修改后的挂点。测试用途的自定义加载来源不能借用 canonical 素材的接触准入。
花饰的局部贴合归绑定提供器所有：只在私有烘焙副本上调整两片花瓣与一片小叶的
刚体局部矩阵，保留原连接点、几何缓冲、源 GLB、挂点范围及动作控制器。
贴合模块哈希参与花饰 attachment 身份；实例仍独占其资源，不添加逐帧写入者。
三个已知花饰/身体交叉在完整动作采样中清除，不代表整套连续接触或披风/喝茶准入。
挎包包体、翻盖与扣件也由绑定提供器施加同一个私有刚体局部矩阵；在待提交装备
已归清理逻辑所有之后执行，失败释放资源并保留旧装。肩带、几何缓冲、材料、
固定点权重和次级运动控制器不变，贴合代码进入 attachment 身份。它修复已采样的
包体/身体交叉，保留连接处嵌接；不代表原缝线逐点约束通过。
穿搭刚体标定同属绑定提供器：挎包绕原弹簧根点调整，日常披风绕 back.upper 原点
后倾 2°。完整组合的实例偏移仍在原挂点范围内；控制器、材料参数和最大摆角
不变，实际摆动轨迹随装配方向变化，不能宣称波形完全相同。标定模块及最终矩阵
一并绑定接触身份；完整 481 帧已无跨装备交叉，但连续接触、包含关系、同件自碰撞
及round5 披风的 65 点/喝茶合同仍未通过。
65 点是内部粗网格作者生成的研究基线，不作为用户要求冻结私有绑定的依据。
`cloth-probe/attachment-profiles.json` 显式保留原 65 点与旧 55 点失败版本；新版
51 点仅改变隔离布料实验的固定点归属，原模型、粗网格、映射和控制器文件不变。
固定点的连续间隙证明不覆盖自由布面或完整衣物。薄布与细节皮肤均检查实际渲染
边长；局部包边截面比较使用独立中间输入和唯一输出写入者，不进入生产准入。
布面细节的 body-frame 候选明确接收刚体旋转，插值粒子位移而不独立旋转相邻
三角面的厚度偏移；原三角框架映射仍为对照。包边截面可在私有输出上与对应布面
边界连接，实际截面圆心/边界误差单独验收，不能借粗网格或固定点通过代替。
区域体积碰撞中的截面中心按去重角采样计算；这些研究候选仍不进入生产路径。
局部 wire 碰撞候选由同一个隔离 world 统一推进；布面与四条包边各拥有私有粒子，
自由接缝用双向约束，重复固定粒子仅复用原支撑位置。细化边界及紧邻顶点使用原
角度/径向参数对应关系；渲染截面由局部真实半径胶囊包住。静止平衡修复不等于
动态通过：该候选仍有细布面应变、接缝残差和 CPU 成本失败，不进入共享运行时。
后续四边位移修正仍只拥有私有渲染缓冲；它不自动成为原生碰撞皮肤，必须分别记录
实际物理面与显示面的反例。直接前包边比较让每个原外表面顶点对应实际碰撞粒子，
接缝约束连接十二个去重样本的真实圆心；仅保留原支撑点，允许截面转动。
双向关节的刚体代理单独设置已声明求解预算，不能误以为软体额外迭代会自动继承。
全包边区域候选以实际布边粒子替代混合固定/自由三角形代理，保留原粗网格和固定点
身份，仍在既定粒子预算内。此候选的自由显示面/物理面合同与性能尚未通过，不设为默认。
共用体积网格候选由隔离 world 同时拥有实际碰撞皮肤及其显示读回，禁止再用另一套
自由布面位移映射充当同一碰撞结果。私有网格生成器只读冻结素材，完整 AABB/重心
包含检查不能退化为固定数量近邻搜索。原生小单元绑定的尺度反例要求世界坐标、
重力、碰撞体和 lengthUnit 一致换算，公共模型坐标、时间与验收阈值不变。
此候选仍有实际应变、接缝及 CPU 失败，静止覆盖和输出一致性不构成生产准入。
自由材料点的圆心连接比较由独立 `centroid-constraints` 拥有：显式实验开关使用原生
粒子附着，避免单粒子刚体代理的旋转退化；共享圆心的第二截面保留原局部锚点关节。
全部 201 条圆心约束、单元、边、质量及碰撞面保留，失败候选仍不进入生产路径。
稳定性诊断只观察同一原生状态的速度、动能、重力势能变化与有向体积；外部快照
在目标姿态已写入且步进前保存，不钳制速度，也不将有限值等同接触或应变通过。
取消诊断的最低时长为原 9 秒；晚取消按未改动的控制器 `done` 补齐尾段，禁止因
固定采样上限截掉退出过程。该时长计算只属于外部诊断，不拥有应用时钟或状态。
刚性挂件的连续分离证书只适用于同一刚体变换、单骨权重、无挂点 morph、无独立
局部运动的几何域。花、叶、光环满足这一有条件的几何证明；披风、挎包及身体相关
配对仍需独立连续接触证明，不能从 481 帧无交叉推导。所有诊断仅写外部证据目录。
接触动作从空闲可见且无待处理手势/换装的边界启动，指针抢占、隐藏、低动效、
取消、换装、reset 与销毁统一释放动作所有权。reset 失败须清理整个角色。

研究 Node fixture 与浏览器演示共用 `integration/foundation-runtime.mjs` 和
`binding-provider.mjs` 的完整组合，文件读取与实际浏览器纹理加载各自位于适配器。
换装完成加载、解码准入、挂载、独立有界特效和动作策略构建后才提交新的装备快照。
构建失败保留旧装备；提交后的旧资源清理异常通过结果的 `cleanupError` 返回，不能
变成可重试的换装失败。旧新装备各有四槽特效池，临时资源归待提交请求预算。
当前浏览器演示包括原始部件与五挂载组合，但连续接触、服装与动作兼容仍未验收。
整套组合使用独立 fixture：光环沿 crown 法线偏移 0.04，保持既有挂点限制和源模型。
这仅修正已采样的光环/花瓣交叉，不代表其余装备接触已通过。表面审计使用实际
最终姿态网格和可见性；离散采样、包含关系和连续碰撞证明分别记录。
喝茶是独立研究回放，不与装备共用动作准入；书本释放只采用既有简化刚体碰撞。
实际录屏使用明确的逐帧采样时钟，不作为目标设备实时帧率证据，仍受
VALIDATION「V2 研究基础能力验证」的性能、视觉、原生输入及 GPU 门禁约束。
