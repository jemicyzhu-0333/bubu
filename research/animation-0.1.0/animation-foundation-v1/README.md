# Animation foundation research checkpoint

Work in progress. This checkpoint preserves source and tests before final integration and independent review. It is not production admission, batch-rollout approval, or a performance guarantee.

Includes anatomical anchors with explicit character profiles, authored action configuration and single-owner expression composition, bounded accessory effects, mature spring-bone/Rapier adapters, resource accounting and a research integration harness. Accepted character geometry is referenced, not duplicated.

The local fixture adapters still refer to the source workspace layout; portable package wiring and a clean-checkout reproduction remain outstanding. Install dependencies separately using the pinned secondary-motion lockfile and ensure one Three.js 0.186.1 instance. Do not treat workspace symlinks as a reproducible package installation.

Known remaining gates: current full integration and source-hash review; actual motion/silhouette and wearable-palm contacts; transparent native-window/GPU performance and resource recovery. Spring tail proxies are not cloth self-collision or mesh-contact guarantees. No main-branch or release change is included.

Old generated benchmark reports are intentionally excluded from this source checkpoint because the body-floor algorithm changed after those runs. Tests and their source are preserved; fresh evidence will be committed separately.
