# Anatomical anchors: read-only D2 / hybrid prototype

Owns only mount definitions and sampled transforms. No persisted state, events, timers, renderer globals, face edits, copied body, material ownership or production deep imports. The runtime receives actor handles from its composition owner. Tests alone use immutable research fixture paths.

## Contract

`createAnchorRegistry({ THREE, sourceSkin, hybridRoot, profile, assertSourceCurrent, assertPoseCurrent })`

Generic implementation lives in `registry.mjs`, `profile-admission.mjs` and `weighted-frame.mjs`; none import a character, generated anchor table or research fixture. `bubu-d2-profile.mjs` explicitly owns D2 geometry names/counts, seven-joint requirement, source hashes and anchors. Supply `BUBU_D2_PROFILE` from composition, or explicitly call `createBubuD2AnchorRegistry(options)` in D2 fixtures. The generic factory never assumes a default character. Profiles are trusted authored descriptors, structurally validated and defensively copied once, not arbitrary downloaded plugins. Existing source admission/ownership guard is responsible for verifying declared asset hashes before handles are given to this module. No full asset hash runs per frame.

- `hybridRoot` is the actual mixed-binding owner's root, attached alongside this actor's original skin, not a GLB template.
- Required ownership guard must reject revoked/foreign actor handles. Required final-pose guard must reject any revision that is not the current completed pose.
- Owner evaluates base/action pose, updates world matrices, then calls the hybrid owner's update (including rigid hand overrides), then `registry.sampleFinalPose(poseRevision, activeAnchorIds)`. Omitted active IDs explicitly samples all admitted IDs; `[]` samples none. Requests must be unique and admitted. Unsampled IDs fail closed rather than returning old transforms. Portable hosts pass only mounted/effect/contact IDs.
- `registry.getTransform(id, { poseRevision, offset: [0,0,0] })` returns an independent world-space THREE.Matrix4. Optional `target` writes to a caller-owned Matrix4 to avoid output allocation. It never returns shared internal scratch state. Omitted revision means latest sampled revision, still checked against caller's guard and a bone/world/bind-inverse matrix fingerprint in a bounded reusable numeric buffer sized only to bones with nonzero influence and part matrices required by the requested anchors. Different admitted profiles may use different bone and part counts (limits: 128 bones, 64 parts, 256 anchors).
- A renderer with a nonidentity parent computes `inverse(parent.matrixWorld) * worldAnchor`. An effect adapter may call `target.copy(registry.getTransform(id,{poseRevision}))`. No Object3D is created or added by the registry.
- `registry.ids` / exported `ANCHOR_IDS` are the closed list. `registry.definitions` / `ANCHOR_DEFINITIONS` are deeply frozen. Unknown IDs, stale pose, changed skeleton/binding/part identity, singular matrices and out-of-bounds offsets fail closed. `dispose()` only drops private records.

## Frames and slots

25 finite slots: crown; forehead; templeL/R; earL.front/rear and earR.front/rear; neck.front/back/sideL/sideR; shoulderL/R; back.upper/lower; hip.sideL/sideR; palm.gripL/R; footL.top/footR.top; soleL/R; tail.root.

Source geometry front is +Z and anatomical L is negative X, matching original joint/mesh names. Local frame +X is tangent, +Y bitangent, +Z outward normal. Ground-facing sole normals point down in rest pose; moving feet carry their actual final-pose normals. Palm grip frames are front-facing surface contacts and follow actual rigid hand overrides, not an inferred shoulder location. These are attachment regions on the approved body, not 25 new anatomical bones.

The generated definitions contain exact hybrid vertex IDs, position, original normal, local axes and original four-component joint indices/weights. Generator semantic regions are specified relative to measured part bounds, then projected to a compatible existing surface vertex: there are no hard-coded world-space support points. Runtime requires selected vertex/weight agreement with the injected geometry. For native body/feet it evaluates the injected Three mesh’s getVertexPosition, including absolute/relative position morphs, skinning and nonidentity inverse binds. Authored normal morphs follow Three absolute/relative semantics before inverse-transpose deformation; absent morph normals preserve the authored base normal, matching the renderer rather than inventing normals. The tangent is transported with the changed local normal and re-orthogonalized. Normal uses inverse-transpose; tangent is transformed and re-orthogonalized. Rigid palms use their final mesh world matrices. Result is a unit right-handed attachment frame, deliberately excluding body stretch from accessory scale.

Offsets are in frame coordinates/source model units: tangent X and Y each ±0.025; normal 0…0.04. These are conservative mount adjustment envelopes, not accessory collision guarantees. Larger asset-specific rest-origin/geometry design is a separate authoring concern; halo height should be geometry relative to crown, not an unbounded mount translation. A small finite next set can be compiled only after authoring and review, never auto-created from a misspelled ID.

## Evidence and limits

`node anchors/tests/actual-pose.mjs` from the foundation root replays actual recorded drag (271), longpress (1,891), and actual rigid tea controller (271) against unchanged source/hybrid files. It checks actual skinned vertex equivalence, nonidentity inverse binds, independent actors, stale pose, copied transform mutation, offset/missing/disposed failure and unchanged source geometry arrays. `review/validation.json` records numerical results. `python anchors/render-review.py` compiles definitions and renders four labeled static views in `review/four-view-anchors.png`; faces are intentionally omitted from this diagnostic mesh plot, not modified in the actor.

This is CPU/research evidence, not browser/native-device performance acceptance, collision acceptance, wardrobe eligibility or proof of continuous cloth contact. Owners must not mutate borrowed source geometry; this registry checks selected vertex data on admission plus stable attribute/index identities, layouts and Three version counters per frame, not a costly full-asset hash every frame. Owners must set needsUpdate after buffer edits; admitted topology/attribute edits require rebuilding the registry. Morph influences may change between final poses, and are fingerprinted for selected parts to reject changes within a sampled revision. Morph target counts are bounded at 128. Source bytes and complete geometry are independently checked by the test/evidence pipeline. It does not schedule animation, make an asset dynamic, or solve a garment fit.

## Character extension regression

`node anchors/tests/profile-extension.mjs` validates a second synthetic character with two bones, one part and unrelated mesh/anchor names. It verifies exact weighted vertex equivalence, missing explicit profile rejection, private descriptor isolation, subset sampling, and rejection of a profile whose vertex ID was moved without matching its authored source position. This proves mechanism extensibility, not admission of another shipped character. Full18 remains unsupported until its own verified profile exists.
