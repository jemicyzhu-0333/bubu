# v6 独立源审查（局部提取建议）

结论：可以开始隔离的 palm-only 候选试切；不能直接验收整臂/固定肩链，也不能声称已经具有完整前掌＋后掌抓握层。v6 有把手孔、三高度和连续腕掌，且没有闭合腕圈/遮眼。以下坐标均为原 2172×724 PNG 的像素坐标。

## 身体比例与掌大小

高 alpha 躯干最大宽：低651px（x61..711）、中659px（x756..1414）、高652px（x1461..2112）。差1.2%，如实保留；每格各用一个等比比例映射 canonical body 69.415385：低0.1066288556，中0.1053344234，高0.1064653144。不能只把手/臂纵横不同缩放。

低格近杯掌的明确外轮廓约80–90px宽、95–100px高，即约8.5–9.6×10.1–10.7 art units。近 wrist 的边界并不由封闭黑线定义，扩大根侧切口可以增加宽，但不能因此把一段前臂宣称为更大掌。相对已有13×13 hold envelope，源掌仍偏小；相对10×12 rest更接近。先看候选正常尺寸，勿宣称原hold大小已保持。

杯浅色区域含把手外伸部分大约233–236px宽、142–150px高，计入黑外框后约25×16–17art；不是准确的22×19原杯。提取时不得使用源杯替换当前杯。

## 放到真实接触后的限制

独立掌可以等比提取后按真实cup contact做平移，杯不动、固定S不动。可先以hiccup左右(22.875,48.375)/(42.5,48.375)做隔离候选，清楚区分左杯壁边界与右把手轴/外边缘语义。源右侧只支持外边缘，当前42.5目标若定义轴心，必须建立有来源的边缘→轴心偏移；不能把两者名称混用而宣称零误差。

wrist root 平移后的新位置必须交给6+6固定肩链重新求解；保留原fore源，按源支持的局部轴向重叠，不拉伸整臂，不挪肩。此处只提供开放腕切口，不证明新root可达或肩外轮廓被遮住。若需补不可见后掌/新根外轮廓，这张源不提供该证据。

早先v6-registration-diagnostic.json只记录一种宽度/桥顶假设下的探索注册，不是结论，也不是已观察源肩根。最终建议不使用该全身注册来硬搬整条源臂。固定S仍严格沿manifest，不从生成躯干倒推更方便的肩。
