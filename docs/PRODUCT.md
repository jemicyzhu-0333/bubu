# 小步（bubu） 产品与交互原则

本文是产品行为的事实源。使用入口见 [README](../README.md)，工程实现见 [ARCHITECTURE.md](ARCHITECTURE.md)，
验证边界见 [VALIDATION.md](VALIDATION.md)。

## 产品定位

小步（bubu） 是本地优先的执行功能伙伴，不是“监督用户完成更多事情”的绩效工具。它优先解决四件事：降低开始成本、
把工作记忆外置、让时间可见、让中断后的返回足够容易。

核心闭环不依赖模型。只有用户明确开启并配置自己的 OpenAI 兼容 Provider 后，拆解、补全、卡住建议、多轮澄清
和闪念能量判断才会调用它；所有模型产物都要经过用户确认或有界校验。小步（bubu） 不联网分析桌面，不推断情绪，
不诊断 ADHD，不是医疗器械。
设置中可在开启 AI 前手动「测试连接」：仅发送固定测试文字，验证当前输入的模型与 API 是否能响应。
测试不保存配置或启用 AI，可能产生少量服务商费用；连接成功不代表所有 AI 任务协议都兼容。

测试构建可在「设置 → AI 助手 → AI 诊断（测试版）」主动开启30分钟的本机临时查看。
可核对模型实际可见回复、格式整理、校验、采用门槛和真实提交结果；这不是模型内部思考。
默认不采集、不落盘、不上传，停止/到期/退出清空，来源删除或变化清除关联正文。内容可能包含私人原文，遮罩与截断会标明。
仅提供主动生成的无正文元数据导出。诊断不增加模型调用，不改变分类、情绪或能量规则；未记录的实际能量贡献明确说明。

## 不可破坏的原则

1. **行动小于规划**：先给出可立即执行的一步，不要求用户先维护完美系统。
2. **选择权属于用户**：提醒可延后、动效可降级、任务可恢复，自动化不替用户做不可逆决定。
3. **恢复也是进展**：暂停、中断和漏做不抹掉已有成果；回来继续需要被看见。
4. **反馈必须真实**：不声称读懂情绪，不把启发式分数包装成客观重要性，不显示未实际入账的奖励。
5. **奖励行动，不惩罚症状**：不因逾期、中断或低活跃扣 XP、默契或库存，不做连续打卡，不用随机失败制造损失厌恶。
6. **安静是默认能力**：提醒、声音、动效、视觉刺激和伙伴主动程度分别可控；必要状态不能只靠动画表达。
7. **本地数据优先**：核心功能离线可用，桌面内容和用户行为不因“智能化”默认外发。

## 面板交互

主导航为现在、安排、回顾；安排包含任务、日常、收件箱、已归档并记住位置。伙伴从页眉进入。新任务只要求标题，步骤、日期与其他属性渐进披露；折叠不清空值。保存按钮、关闭与标题在可滚动表单中始终可达。
主面板默认 560 × 680 DIP，按工作区收缩。Windows 首次居中并支持顶部拖动，macOS 从菜单栏展开；等待首次绘制与布局后显示。应用仅驻留托盘/菜单栏，Windows 不进入任务栏，macOS 不显示 Dock 图标。
自评支持鼠标预览、松手一次保存与键盘选择，取消不保存；低刺激/减少动效下不缩放。导航与伙伴页装饰在隐藏或减少动效时停止。错误、保存回执和模型不确定性必须明确可见。
随手记空闲时用于捕捉，执行中显示计时和未完成步骤；记录成功后回执再关闭。伙伴联动不能覆盖手动拖动，低刺激/减少动效不搬动宠物。
升级、解锁、归档与回顾等日常反馈交给可见桌宠，隐藏时不唤出；到期、预约与计时通知不依赖桌宠可见性。

## 执行闭环

```text
捕捉 → 澄清 → 选择 → 启动 → 陪伴 → 落地 → 续接 → 恢复
```

### 捕捉与任务

- 面板最底有一行常驻的“随手记”，任何页签、专注中都能用（面板里按 `/`）：一句话进收件箱，不打断手上的事。
  开了“用 AI 分拣随手记”后，收件箱会为每条给一个建议去向（转任务、记日常、记状态、放下情绪、留作想法），
  点一下才生效；情绪不影响能量。
- 闪念先保存，避免切换上下文。分类区分任务、日常计划、日常记录、状态、情绪、想法；不确定显示未分类，不把建议当作确定结论。每条可手动更正，迟到的 AI 不得覆盖本人选择。 分类进度、不确定、未开启和失败通过卡片状态及按需帮助区分；未保留的过去执行结果不冒充失败，也不会自动补跑。
- 收件转任务先保留原文并创建任务，再展示可编辑的拆解建议；确认前不写入任何模板步骤，也不记为完成拆解。取消或生成失败时保留无步骤的任务，可稍后编辑或重新拆解。
- 收件操作按类别提供：任务可转任务或预约；日常计划可创建日常；刚做过的事可记录一次，没有对应日常时同事务创建；情绪保存私密记录；想法直接留存。内置日常同类多条时必须选择；自定义类型已有任何条目时必须明确选择已有条目或新建，不因同属“其他日常”而自动关联。计划不冒充完成。
- 日常记录名称优先使用同一次 AI 分拣返回的活动名称；没有有效名称时保留原文供编辑，不把类型标签当名称，不伪称 AI 已起名，也不为补名称额外调用模型。本人编辑的名称（包括清空）优先于后续建议与重绘。新建并记录会增加一个仅手动记录的日常条目和一笔发生记录，不自动设置提醒；已有条目的提醒设置不因记录而改变。
- 收件卡片默认只显示一个主要操作；预约、只留存和删除收进省略号，展开为锚定菜单，Escape 收起并归还焦点。历史卡片的菜单位于头部，不用额外操作底栏撑高卡片。未分类的卡片直接给出“要做的事 / 刚做过 / 想养成 / 状态 / 情绪 / 想法”一排选择，主要操作是“先留存”。改分类、日常类型、能量档位或目标日常只是这张卡上的草稿，标注“未保存”，按主要操作时才与动作一起保存，方向键浏览选项不会写入任何东西。日常与能量字段直接以紧凑的行内输入展示，不再重复一个“日常设置”折叠标题；需要明确选择目标时，未选前不能提交。待整理至少两条时提供“全部留存”，需要连按两次确认，原文与标签全部进入历史，不删除任何内容。
- 除显式“删除收件”外，整理时保留原文、分类、保存时间和处理结果到历史，同一事务写入目标与来源；历史不自动清理，存放在本机的事实存储里，不让设置文件随时间变大。旧版已移除的收件无法恢复；现有待整理条目和 AI 分类会保留。删除情绪记录也清理对应收件历史；来源暂不可用时明确拒绝或保留待清理结果，不把读取失败说成空历史。情绪记录已不在当前列表而来源仍在时，历史显示“来源记录仍保留”，只有本人重新确认“删除关联来源”后才清理这条情绪对应的原文；不把这种缺失推断为上次删除失败。
- 手动选择非状态类别会撤回该条的 AI 能量修正；状态确认替代该条的推测信号，不能覆盖更新的自评。超过日常两日记录范围的旧条目可留存原文，不静默生成随即被清理的打卡。
- 任务只要求标题。重复、计划日、可开始时间、截止、自动失效、标签、能量、估时和步骤都是彼此独立的可选属性，
  在编辑面板里渐进披露；改一个不会暗改另一个。模型里没有项目、负责人、位置或另一套优先级。
- 截止对任何任务都可选；自动失效只在用户明确开启时存在，预约任务的失效从预约时刻算起。
- 任务页是一份单列表加一组筛选（可做 / 今天 / 重复 / 有截止 / 等待中 / 已完成 / 标签）。筛选只是视图，
  一件任务可同时命中多个筛选；计数为 0 的筛选不显示。
- 重复任务按系列生成下一次；漏做不扣分，也不堆出一排逾期。编辑重复任务时先选“仅本次”或“本次及以后”。
- 每次打开任务编辑面板都是独立草稿，包括重开同一任务。任务保存、未来规则和系列状态一次只提交一个操作；失败保留输入，允许本人重试。
  关闭不撤销已发出的保存；旧操作的迟到结果不能关闭新草稿、替换提示、归还焦点或解除新操作的等待状态。
- 完成是终态：有未完成步骤时先确认，确认后立即结算，不提供重新打开。继续类似工作用“再做一遍”复制。
  唯一的例外是手滑：完成后的提示条上有 5 秒的“撤销”，点了就整体回到完成之前（奖励、统计、时间线记录一并撤回）。
  升级、解锁皮肤、羁绊阶段变化、或者完成时动到了正在走的专注，这几种通知与计时状态已经对外发生，不提供撤销。
- 任务的删除与自动清理都进可恢复归档；个人收件和情绪记录的显式删除移除原文。

### 澄清与选择

澄清记录“卡在哪里”和“下一物理动作”，也可以把任务拆成步骤；步骤有稳定 ID，插入、重排或再次澄清不改变已发生
的奖励身份。

推荐在全部当前可执行任务上分别计算“综合优先”（截止、逾期、能量匹配、时长、下一步清晰度、启动阻力、近期选择）
与“最容易开始”（独立优化启动成本）。两张卡是展示上限；同一任务同时胜出时合并说明，不伪造第二名。未到预约、
已完成、已归档或过期未续期的任务不进推荐和新会话。

### 启动、计时与落地

页眉固定显示本地日期、星期和当前时间，与会话倒计时分离。运行中的计时圆环带低频呼吸与扩散光晕，暂停即停住；系统减少动效、产品减少动效和低刺激模式均禁用。

桌宠采用星轨显示本轮进度，底部用SVG图标与对应颜色区分专注、休息、暂停、待确认、关联任务已完成、需要处理和本轮结束待落点。
空闲不显示会话文字区；倒计时与完整名称放在悬停说明和可访问名称里，点状态打开原面板处理。减少动效／低刺激时进度按30秒更新，
暂停与待确认不自行前进。当前休息优先显示，未回答的专注落点仍保留在面板。活动标识只使用已有真实信号，不因图标设计开启新的采集或自动轮播。

- 今天页开始前直接调本轮时长：5–120 分钟，`−5 / +5` 与 15、25、45、60、90、120 快捷值；新安装默认 60。
  运行中可以延长，也可以缩短到不早于已投入的时长；缩到“现在”必须显式“结束这段”。
- 同一时刻只有一个专注、两分钟或休息会话。暂停不计时；跨午夜按真实活跃片段拆到各自的日期。
- 两分钟是卡住时的低承诺救援，可从“有点卡”弹窗或快捷面板的候选任务启动，必须已有明确的下一动作。
  快捷面板里只有标题的任务先展开本地输入，明确确认后才一起保存下一动作并启动两分钟；取消不保存输入。
  任务变化时保留输入并要求重新选择，不把旧输入套到新版本；已有下一动作的任务仍直接启动。结束时由用户选停下、再做 8 分钟
  或按今天页选定时长继续。启动已经成功而窗口关闭失败时，明确显示已开始，不能再发一次启动。
- 结束后可以保存“下次先做”，它作为新步骤加入清单，不覆盖已有步骤。已有待处理落点时，新会话和健康收工不能覆盖它。
- 成功恢复专注或两分钟启动算一次“回来”。休眠自动暂停；退出或离线期间到点的会话进入待确认，确认只结算一次，
  放弃不发奖励。暂停的关联任务若已完成、缺失、跳过、失效或预约未到，不能继续计时，并显示原因；自由专注和休息不受历史任务状态限制。
  到点显示“确认计入完成”和“放弃本轮”，只有显式确认才按当前规则结算已投入的一轮；确认可以处理已完成或已缺失的关联任务，不能重开任务。
  恢复状态与剩余时长不一致时，确认和继续均禁用，仍可放弃本轮。休息只提供计时操作；已完成的关联任务在快捷面板中只读。

### 卡住时

今天页的当前任务卡只有一个处置入口“有点卡”。弹窗先问一次卡在哪（说不清、太大、无趣、有压力、没电、被打断），
再给三条写明代价的出路：**换个更小的下一步**（会改这件任务的下一动作与卡点，确认前不落库）、**试个小办法**
（不动任务，读一条本地策略）、**只做第一步（2 分钟）**。策略卡的“有用 / 不合适”不是关闭条件。开启 AI 时，
弹窗上方保留针对这件事的下一步建议，并提供“和 AI 一起理一理”进入共享协作；等待期间先显示本地策略，回退时写明来源。

### 能量估计

能量是 **10–90 的非医学日常估计**，不是电量、能力评分或生理测量。基线采用睡眠稳态压力与昼夜节律的双过程
形状，再叠加睡眠惯性、午后低谷、用户记录的日常事项和短期校正；睡眠时刻来自作息设置，不声称知道真实睡眠。
界面同时显示“估计”、趋势、置信度与当前归因。

“现在感觉”是五档绝对自评（很低 / 低 / 一般 / 好 / 很好），离当前估值最近的一档亮着，再点它就是“差不多”。
专注本身会让估值慢慢往下走，休息后回升；顶部读数和曲线永远是同一个数。
自评历史默认不收集，只有授权后的明确自评和手工调整会留存。查询会使用仍保留的自评和最新一次记录；
其他输入相同时，后来自评不会使已留存的较早自评从曲线计算中丢失。关闭采集保留已有历史，清除历史仍保留最新一次记录。
未保存、已清除或超出容量而移除的记录无法补回；曲线仍会按当前档案、作息、日常和试用参数重算，不是不可变的历史快照。
今天页的能量块默认只有一行（标签 + 读数），点开才是曲线、归因和自评，把第一屏留给“现在做什么”。
每天第一次会问一句“今天几点起的？”（6 点到 11 点后，或跳过），问一次；你说的起床时间只用来校正当天曲线的起点。开启“用闪念
校准能量”后，只有明确、近期、第一人称的状态描述会变成最多 ±12 的短期信号，两小时半衰、一天后归零；计划、
一般情绪、第三人称和模糊表达不改曲线。能量参与推荐，但不越过用户明确选的当前任务。

### 日常事项

日常页与任务页使用同等级的新建按钮。类型通过图标选择；自定义类型可以命名并从已有名称复用，不推断能量效应。重复支持手动记、每天、工作日与选星期；最多六个提醒时间以小时/分钟选择器配置。提醒设置提供总开关、每条编辑与静音、轻提示/气泡/提醒卡片；无条目时也保留总开关和空态。未设置时间的条目标注“仅手动记录”，其“设置提醒”入口打开已有编辑器，由本人选择频率与时间并保存才建立提醒。

吃药、喝水、吃饭、开会这类到点发生的生活事件是“日常”，不是任务：没有步骤，不进专注，不发奖励。

- 可以只提醒、只手动记，或两者都有（“随手记”专指面板底部那行，日常里点一下记一笔叫“刚做了”）。窗口内提醒一次；窗口过去就静静地算没记上，不标红、不计数、不排成欠账清单。
- 不给用药建议：只提醒用户自己设的时间，只记录用户说发生了的事，没有剂量字段，也不说“现在补上”。
- 日常完成永不产生 XP、不影响任何连续计数、不喂桌宠。
- 今天页只留“今天的日常”几行和“刚做了”小按钮；添加、改提醒、删除在与任务并列的“日常”页，
  今天页的“管理”会直接跳转。长期记忆的列表与开关在设置里（“模型知道我什么”的唯一出口）。
- 日常记录（包括用药）不进任何模型请求。
- 每一笔都能撤回；删除一条日常会连带删除它当天的记录。
- 日常提醒最高到 L3；DND 下降到 L1 而不是消失：“别打扰我”不等于“帮我把药忘了”。

### 回顾

工作结束附近生成“今天的收口”（真实完成、专注片段、今天留下的未完成落点、未处理闪念）；下一工作日开工后约 30 分钟生成
“今天的启动”：最上面是“今天先做这几件”——1–3 件、默认勾选（截止最近 → 计划今天 → 昨天延续 → 今天新增），
点“就这样开始”后它们计划到今天，第一件直接成为“现在”；下面仍列出昨天延续、新增和带自动失效的事项。默认时间来自工作时段。卡片按自己的日期命名
（今天的 / 昨天的 / 某月某日的）；前一天没有任何活动时不生成那天的收口卡。事实由本地数据确定性聚合，不调用 AI；
“必做”必须由用户确认，未处理闪念不会被删除或自动变成任务。DND 或错过时机收进右上角回顾入口，角标只数待处理卡片，可中途退出并
从原进度继续。

## AI 能力

**统一执行与记忆边界。** 共享执行层不改变默认关闭、用途开关、本人选择和确认。本机检索只帮助选择，相关性不授权外发；保存记忆也不自动允许聊天使用。模型仅提出候选，纠正/永久移除沿用原预览与确认。
记忆优先保存明确陈述或本人审阅的偏好，不从任务行为或一时困难推断诊断、药物、风险标签或长期人格；建议少而有用、可忽略和纠正，不新增后台画像或审阅负担。语义版本不承诺完整历史查询，unknown/未保存/清理未完成须如实区分。
本阶段到有界记忆检索和既有候选流程接入为止。图片、长上下文增强、列表增强、quick Tab仅设计，不承诺新UI或hide后继续；不新增Provider、远程embedding或资料迁移。

默认关闭，由“启用 AI”、模型名、Base URL 与 API 密钥共同决定；开关打开但缺密钥或模型名时行为与关着相同。
关闭AI会取消当前远程请求并停止后续重试；重新开启、修改后恢复模型或地址，都不会继续采用旧请求的迟到结果。
设置面常显是否就绪；输入参数后显式保存并显示回执。用途说明点问号查看，发送字段在“数据与隐私”内可查。模型不可用、超时、断网或返回不合法时回退本地模板，
回退时写明原因。运行诊断只保留操作、计数、耗时与错误类别，不记录任务标题、对话、收件或记忆正文。

- **拆解**：3–7 步，第一步两分钟内能开始且里面不留决策，每步点出一个动作，一次坐下能做完、被打断可以放下；
  用户逐项编辑后确认，才经既有任务事务写入。模型不能改标题、决定“必做”或自动开始计时。
- **补全**：步骤、完成标准、能量、估时（5–480 分钟）、最多 3 个标签（只能从现有标签里挑）。标题不在请求的输出里。
  没有用到模型时（未开启、无密钥、超时、回退）补全**什么都不填**：只说明“没有用 AI，所以没替你拆”，并把光标放到“加一步”，
  提示先写下第一个看得见的动作。本地规则只能给出对谁都一样的步骤和估时，填进草稿只会看起来像想过。
  模型建议只落进草稿，保存才写库；补全失败时保留原输入，不以通用模板冒充模型结果。
- **持续协作**：新任务与卡住共用对话。可以先聊聊、找一个小动作或一起安排，随时换方式；出现草稿后仍能继续聊和选择旧版本。
  没有六轮倒计时。单条最多8,000个字符；较长会话分段承接，预算不足时说明并保留记录，不假装用户已经想清楚。
  默认仅本次，明确选择“在本机保留”后才可跨重启恢复；默认保留30天，可以固定或删除。关闭只暂停，输入与滚动位置保留。
  发送后立即在对话中显示本条文字并清空输入，可继续写下一条；回复失败或取消仍保留消息，重试不重复添加。
  等待确认的消息不冒充已保存；较晚的回复不会清空新草稿。保存失败明确标为尚未保存。用户能先查看当前任务的实际参考字段，另选当天已记录专注汇总；没有记录不等于没有活动。
  “放进草稿”只填写新任务表单；从卡住进入时只填当前任务的下一步编辑，仍需原有确认。聊天不会自动建任务或计时。
- **长期记忆**默认关闭。开启后只注入用户确认过的记忆和规则汇总的近期概况，界面列出这次发出去了哪几条；
  用户可以逐条忘掉或全部忘掉。模型不能自己写记忆。
- 提示词把产品约束写给模型：启动成本判据、按真实场景拆、不诊断、不说教、不鼓励、不用感叹号、与标题同语言。
  拆解、补全和协作任务草稿只做结构与边界校验，不用动作词表、语言识别或词句语义判断拒绝建议；澄清也不按问号数量判断问题个数。具体措辞留给模型指导与用户编辑确认，本地模板不改写输入措辞。

API 密钥只存系统安全存储，保存后输入框清空，界面只看得到“已配置 / 未配置”。端点只允许经 DNS 校验并钉死地址的
公网 HTTPS（443）。草案最多在内存保留 5 条、10 分钟。

开始前可编辑整件任务；专注及暂停期间可追加步骤，或在随手记中改写未完成步骤。已完成步骤不可修改，任务标题、计时和重复模板不受影响。专注播放图标只作短暂邀请，低刺激和减少动效时静止。

## 奖励与伙伴关系

XP、食票和默契来自可核对的持久事实；业务动作、奖励、统计与食物回执同一次提交，重试或重启不重复发放。

- XP 与等级永久共享，不用于兑换。每级所需为 `min(30 × 当前等级, 450)`；第一天的第一个真实推进获得20奖励加10单位，第一步即30 XP到Lv2。
- 每个本地日最多三个不同任务的推进单位，每个10 XP；同一任务的步骤、本人确认专注进展和完成整件任务共用一个单位。自由专注共用一个日单位。另有一次本人选择收口／休息／健康收工的10 XP，每日合计最多60。
- 每个真实步骤、任务与会话仍记录自己的事实和统计，即使其成长单位已经领过。自动计时结算、点击、AI、日常和喂食不制造进展 XP；收口不等于声称已有进展。
- 新档有6张食票、2颗浆果、饱食65。只有每日首次真实推进给3张食票；只收口不领也不占该资格。没有随机掉落或被动补货。
- 团子和乌萨奇各自记录默契与口味，关系阶段为0／12／40／100。每日推进+2、收口+1、可选照顾+1的资格全档共享，切换角色不补领。离开不会减少关系、食票、库存或解锁。
- 普通手动喂食消费一个库存，增加饱食并记录该角色的口味与手动喂食次数；照顾默契每天最多一次，不给XP。
- 基础餐免费，仅饱食≤45时可选，每日全档最多3次（角色与手动／自动共用），最高补到55；目录名义量为+30。它不占库存、不入商店或口味图鉴，也不发XP、食票、默契或手动喂食纪念。
- 食物图鉴显示库存、口味与当前角色最爱。Lv1开放基础餐／浆果／胡萝卜，Lv2饭团／牛奶，Lv3小鱼／骨头，Lv4甜甜圈，Lv5咖啡，Lv6蘑菇，Lv8蛋糕。票价依次为浆果／胡萝卜1，饭团／牛奶／小鱼／骨头2，甜甜圈／咖啡／蘑菇3，蛋糕4。库存上限每种999，已有库存不受新购等级限制。咖啡没有生产力加成。
- 一起走过包含八枚纪念与伙伴小信，由该角色累计专注、完成任务与普通口味解锁；已获纪念不失效。默契里程碑显示阶段和剩余点数。
- 粉粉兽与乌萨奇Lv1可选；forest3、ocean5、sakura7、flame4、moon6、bat8、crown10、robot10、woodsman7。既有拥有项保留，乌萨奇素材的限制见其 USAGE 与根目录 LICENSE-SCOPE；本文不确认权利人授权。

伙伴开启时按本地规则自动用餐，不依赖AI。每五分钟连续采样，六分钟以内才连续计算；启动、锁屏、休眠、关闭伙伴或长间隔不补扣离线饥饿。饱食保留小数，最低25；09:00／12:30／19:00各90分钟餐窗，自动餐至少间隔一小时、每天最多六次。优先普通库存和最爱，特殊零食留给手动；基础餐另受跨角色／手动自动共用的三次额度约束。
AI用餐建议默认关闭，同时开启AI总开关并配置有效模型／密钥才会请求。每天最多预留三次，每次最多一次传输、等待五秒，不重试修复；仅发送角色、饱食、餐次、可用食物、喜好，建议只能选择可用食物、等0／5／10分钟及本地短句编号。饥饿会立即重评未执行的等待计划，不再请求模型。失败回到本地规则，无候选不预留次数。
用餐反馈只在提交后出现，隐藏、免打扰、安静模式或会话中不主动打断。隐藏、替换或关闭会取消仪式与延迟短句，减少动效时仍有静态反馈。
关闭任一AI开关会原子清掉未执行的用餐建议和预约，同值关闭或在关闭状态下更新其他合法设置也清理残留；不退次数、不改库存或奖励。实际模型／地址／伙伴开关或角色变化也清理已捕获建议，成功更换／清除密钥后立即撤回；失败的设置提交不取消仍获授权的工作。

## 衣橱与套装

衣橱以聚光舞台轮播呈现穿搭，左右相邻预览保持次要层级；按钮、方向键和横向滑动都只浏览，不直接保存。
第一项始终来自已确认的实际装备，配饰区修改这一项。其余套装是独立固定配方，单件搭配不会改写它们。
未全部解锁的套装可预览并显示缺少的条件，不能应用；全部解锁后「一键换装」一次保存整套，清掉同形态未包含的配饰，
保留另一形态的搭配。保存中禁止重复提交；失败或结果未确认时不冒充已穿上，只有实际装备投影能确认穿搭。
舞台按「形象 → 套装名称 → 操作或状态」固定排列。名称区固定 36px、18px 行高，最多两行。固定套装名（含主形象完整匹配时）可作窄范围展示例外：本机衬线/CJK 衬线回退、15px/600、0.12em 字距，两侧短细线；不下载字体，不使用阴影或额外装饰文案。「混搭」及操作、状态仍用普通界面字体，混搭为 13px/500。完整名称须能被键盘用户和辅助技术读取；与下行间隔 4px。当前形态的实际装备完整匹配固定配方时显示该套装名，否则显示「混搭」；预览始终保留对应套装名。下行高度 32px：未穿且可用为「一键换装」按钮，实际已穿为「已搭配」，未全部解锁为「待解锁」；后两者是中性非交互文字，不伪装成禁用按钮。解锁条件使用统一问号说明。保存中、失败和结果未确认另按真实事务状态反馈，不覆盖名称，也不能提前显示「已搭配」。

## 桌面伙伴

专注或休息进行时，宠物脚下有一圈安静的进度环：粉色是专注、青色是休息，走了多少一眼就能看到，没有数字、不闪；
暂停就停在原地，结束就消失，吸附到屏幕边缘时也收起来。降低动效时不是平滑地走，而是每 30 秒跳一格。

### 直接交互

| 输入 | 结果 |
| --- | --- |
| 左键单击 / Enter / Space | 情境台词或陪伴动作 |
| 左键长按 | 抚摸，不打开菜单 |
| 左键拖动 | 移动伙伴；超过阈值后与单击、长按互斥 |
| 快速甩动 | 甩动彩蛋 |
| 右键 / Control-click / 菜单键 / `Shift+F10` | 打开命令菜单 |
| `Esc` | 关闭菜单或浮层并恢复焦点 |

命令菜单是贴着伙伴的一列文字按钮：开始专注、快速记录、打开面板、免打扰、隐藏伙伴，朝屏幕上空间更大的一侧打开，
伙伴默认在右下角时也完整显示在屏内。喂食用伙伴旁的常驻按钮。

### 场景、动作与吸附

- 场景是低对比、无硬边框、向透明桌面羽化的氛围层，伙伴始终是主体；自动轮换不出现雷雨，主动换景后才用完整场景池。
- 专注与休息各用一个安静房间和可切换的动作（写文档、打字、读书、浏览网页、整理便签、看行情；发呆、喝茶、看窗外、
  小憩、伸展、照料小苗）。
- 吸附按可见伙伴区域相对当前屏幕工作区判断，进入与离开阈值不同，避免抖动；吸附后只保留伙伴，指针靠近会探头。

### 跟着你（活动镜像）

设置里的“伙伴跟着你”默认关闭。打开后，伙伴按有效的本地活动信号陪伴你：音乐播放器正在出声就跟着摇摆，
编辑器、IDE 或终端在最前面就敲键盘，已接入的 AI 工具收到提问且尚未通知结束时才陪着使用小电脑。
仅有 AI 窗口在前、会话仍打开或刚回答完，不算正在对话；收到本工具的结束通知就立即退场，不再追加阅读等待。
听歌时两种形态佩戴轮廓清晰的软垫耳机，轻轻点头和抬脚；AI 场景以小电脑和身旁拿着空白便笺的小机器人表达一起整理思路。
机器人只是陪伴演出，不会访问其他 agent、读取任务或执行协作。动作不读取音乐节拍，
也不表示 AI 此刻正在思考、输出或完成回答。优先级是：未结束的 AI 工具提问通知 > 写代码 > 听音乐；离开键盘两分钟后只保留音乐。
前台/音乐新状态持续约 15 秒才跟随，回到无事可跟约 30 秒，切窗口不会让伙伴来回抖；AI 工具的提问和结束会立刻生效。
结束只撤回该工具的信号，保留其他仍有效的 AI 工具与音乐；缺少结束通知的提问最多保留十分钟。插件只有工具来源，没有会话或请求身份，不能区分同一工具内的多个并发会话。专注保留实际选中的原会话动作，休息清退镜像道具；
镜像不给奖励、不写入任何记录，自主小剧场可以短暂打断它。首次出现和自然结束有短暂入场、收势；
同类信号刷新和动作循环不重复入场。点击、长按、拖动及休息立即优先；减少动效或低刺激时直接保留静止姿势。

音乐/AI 类别首次出现且没有其他讲话或更高优先级状态时，分别短暂说“音乐陪你慢慢来”或“一起理理思路”，
随后在伙伴下方显示“音乐疗愈中”或“AI协作中”。“疗愈”是轻松陪伴文案，不是医疗效果或治疗承诺；
“协作”是机器人陪伴演出，不是 AI 实际生成阶段或额外执行状态。只有独立信号确实同时有效时才组合：音乐 + AI 保留一台电脑，追加耳机和侧边机器人；专注保留当前真实会话动作，只加安静耳机/机器人，不再塞第二套手持工具。
最多一个主动作、两个轻量附加元素和一行标识，例如“专注 · 音乐 · AI”。前台应用类别不能证明用户正在读书、开会或实际生成回答。
短句被阻挡就略过，不排队补说；同类补发、信号减少、动作循环、切换形态或恢复可见都不会重复讲话。低刺激、减少动效时只保留静态标识与道具。
睡觉、困倦、饥饿、休息、暂停、点击/长按、拖动、菜单、吸附/探头与既有讲话优先；耳机、机器人、悬浮标识共同让位，
恢复时只跟随主进程判定仍有效的最新组合。短句和悬浮标识交替使用同一下方区域，不盖住长耳、帽子、五官或既有对话。

它只在本机看两样东西：最前面是哪个应用、哪个音乐播放器正在出声；不读窗口标题、歌名、网页或对话内容，不保存，不发送。
浏览器、视频与会议应用的声音不算音乐。macOS 与 Windows 都不需要额外授权。

AI 工具可选接入：应用随附一个 `bubu-companion` 插件，第一批支持 Claude Code、Codex、Cursor、Qoder 与 WorkBuddy / CodeBuddy。
设置里按工具列出安装步骤和一条可复制的命令（Windows 上只列出确认可用的工具）；应用本身不改写任何工具的配置，安装、更新和卸载都在各工具自己的插件管理里完成，
Codex 还会请你信任插件里的两条 hook。插件只在“提问了 / 回答完了”时通知本机伙伴，不发送提问、回答或文件内容。
是否接入以伙伴真的收到过该工具的信号为准，面板显示最近一次收到的时间。其他支持 Claude 格式 hook 的工具（如 DeepSeek Harness）可以手动加入同样的两条 hook。

### 自主惊喜与表达

自主行为由主进程统一决定，遵守可见性、菜单、拖动、DND、敏感前台、低刺激、Reduce Motion、专注状态、冷却、
近期防重复与每日预算。伙伴主动程度只改预算，任何档位都不能绕过硬门禁。

图鉴发现只在伙伴表演完成后记录，取消或拒绝不算发现；同一发现保留首次已存的时间，重试与重启不重复计入。

伙伴有 32 套原创表达。表达只陈述伙伴动作和已发生的确定性事实；逾期、跳过、中断、长时间未操作或能量估计都
不会被解释为用户的情绪或动机，不触发责备、失望或惩罚。注视只跟随同一屏幕内的光标方向；菜单、睡眠、隐藏、
减少动效或低刺激时回中。表情、注视和动画都是易失状态，不写入持久化，不记录光标历史。

## 提醒与感官

| 设置 | 控制 | 不应改变 |
| --- | --- | --- |
| DND | 未经请求的提醒、主动气泡和自主 cue；本人排程的日常仅保留静音系统通知 | 已提交状态；用户主动操作的必要反馈 |
| 动效强度 | 过渡、位移、粒子和动画 | 状态可辨识性 |
| 视觉刺激 | 装饰密度、对比和自主视觉内容 | 核心控制与静态状态 |
| 伙伴主动程度 | 自主 cue 的预算和频率 | DND 与其他硬门禁 |
| 声音 | 通知声音 | 视觉与业务状态 |

“减少动效”始终静态；“平衡”在系统 Reduce Motion 开启时也静态；“完整”是明确覆盖系统偏好的选择。非勿扰且前台已确认安全时，提醒的 L1 保留由桌宠承载普通日常与专注过程中的定期询问，不同时发两次；桌宠不可用、会议白名单、专注/休息到点、预约及高优先级提醒保留系统通知和原有动作。之后仍按用户配置的最高等级进入
L2 角落角色、L3 多角角色、L4 半屏选择卡递进，专注与休息的最高等级分别可设；L2/L3 不主动抢焦点，会议或演示应用
在前台时只到 L1；前台未知同样保守停在系统通知，送达失败不改用遮盖窗口。低刺激下 L3 不做四角聚拢。
白名单最多100项，每一项都参与前台匹配；已有本人设置不因默认名单更新而被替换。平衡动效下，系统探测只要有一项明确要求减少动效，就保持静态。
每次升级和高等级表面就绪时重新确认前台；转为会议或未知后，该次提醒保持L1，不在切回安全应用后突然重放升级。Windows提醒独立读取一次前台进程身份，不依赖活动镜像开关；系统策略拒绝探测时同样保守降级，不更改执行或安全策略。

日常的完成或“今天跳过”只作用于提醒所指的那一次，提交失败仍可重试。延后会采用当前标题与设置，已完成、跳过、停用、删除、改期、过窗或关闭提醒后不再重放。勿扰期间日常仍可静音提醒与延后，不升级为角色或覆盖窗口；系统通知的两个按钮为完成和延后，角落卡可另提供跳过。

## 界面语言

角色保留自己的美术语言，工具是原生。本节是所有主面板、子面板、弹窗、快捷面板与桌宠工具的统一文案、视觉和交互判据；`src/surfaces/popover/styles/theme.css` 实现主面板主题，共享外观在 `src/surfaces/shared/interface/`，各功能只拥有自己的结构。角色坐标与素材约束见 [PET_VISUAL](PET_VISUAL.md)，Rig 实现见 [PET_RIG](PET_RIG.md)，检查与证据见 [VALIDATION](VALIDATION.md)。

0. **外观默认为跟随系统，可明确选浅色或深色。** 设置的「通用」组使用三项单选；主面板、快捷面板、桌宠菜单和提醒卡即时共用语义配色，系统原生控件由同一主题来源驱动。伙伴换装不改变工具配色，主题也不重绘角色美术。正文、次要说明与主按钮对比度均 ≥ 4.5。
1. **文字先说明目的，图标辅助辨认。** 主导航使用清楚的文字；只有图形的控件必须有 `aria-label` 和提示。普通标题不强加装饰图标。
2. **角色美术不扩散到工具界面。** 桌宠和伙伴页共享同一套形象，按形态保留像素或原生矢量笔触，不重新量化矢量曲线；面板用系统字体、平滑渲染、统一间距、分级圆角和 1px 分隔线。
3. **一种强调色。** 面板强调色只标主动作和当前选中项；红色用于真正的错误，待回顾使用普通强调色提示。低能量、逾期提醒都不是错误。
4. **不用 emoji 当图标。** 需要图标时用一套 1.5px 描边的内联 SVG；大多数标题不需要图标。食物、日常种类和时间轴
   标记是物品插图，可以保留。
5. **文案是陈述句。** 不写命令（“别分心”）、不写自我辩护（“很可能不准”）、不写内部术语（“可解释候选”）、
   不加感叹号。按钮用动作：“有点卡”“换一件”“结束这段”。
6. **解释进工具提示。** 界面上只留当前操作需要的一句话，排序依据等补充说明放进可聚焦、可关闭的帮助提示或文档。删除后果、隐私外发、费用、权限、迁移和结果未确认等决策所需信息不得隐藏。
7. **数字用等宽数字，不用等宽字体。** 计时器用 tabular-nums，跳秒不抖。
8. **状态决定布局。** 专注中的今天页只留当前任务、剩余时间和暂停/结束；空闲时不重复显示时长。

面板结构：页眉为时间、快捷记录、免打扰、伙伴与设置；主导航为现在、安排、回顾。底部常驻随手记输入与发送。
现在页以具体下一步为主标题，任务名作为上下文；没有写下一步时主标题是“打开材料，只做第一小步”，不重复任务名；没有选定任务时说明“还没有选定任务”，有可做的任务才显示“换一件”，没有任务时不显示“有点卡”。时长默认只有摘要，调整时展开。下面是「今天」一栏：能量、日常、收件箱三块等宽并排，各给一个数和一句话；点能量或日常在下方展开细节，同一时间只展开一块，有到时间的日常时默认展开日常，能量不会因为新一天的起床问题自行展开（只在能量块上提示“今天几点起？”）；点收件箱直接进入「安排 › 收件箱」。专注、暂停与休息时整栏收起。
任务使用连续列表，新建入口与可做 / 已完成筛选共用一行；行内动作可见且支持键盘。日常数量显示在子页签，页面从“今天的记录”与新建入口开始。回顾累计指标与待回顾入口统一按图标、文字、大数字排列；待回顾消息归属回顾页的弹窗。
设置以默认收起的功能组呈现，标题即折叠开关。最前一组为「通用」，统一放置语言和界面主题：语言可选跟随系统、简体中文、English，以语言本名显示，不用国旗；主题可选跟随系统、浅色、深色。这里不平铺操作解释，English 的预览边界用选项中的短标记保留，完整范围见下文；保存失败、实际错误和更新确认等必要反馈仍显示。「应用更新」沿用统一线性图标。功能组收敛为「通用」「伙伴与动效」「专注与节奏」「提醒与免打扰」「安排与能量」「AI 助手」「应用更新」；快捷键归通用，感官与活动跟随归伙伴，策略和回顾归专注，声音归提醒，校准与试用仍保留独立小节和各自确认。语言和主题成功保存后即时生效；失败保留原设置并给出可读回执，不重启、不清空草稿、不搬动焦点。字段和控件优先同排，空间不足再自然换行；互斥选项用单选或分段控件，多选保持独立勾选语义。分隔线仅用于顶层功能组，组内用间距区分。伙伴的形态专属美术保留，周围工具沿用统一的字体、按钮和配色。

共享控件按语义选型。尺寸与状态外观由共享控件和令牌维护，功能样式只负责布局和明确的例外；字段与操作间距统一为 8px。

| 控件或内容 | 统一约束 |
| --- | --- |
| 字体层级 | 弹窗/抽屉标题 20px/600，功能组 15px/600，小节 13px/500，字段 13px/400，说明 12px/400；当前下一步和计时数字保留各自层级；小计数等既有 11px 例外不扩展到普通字段。 |
| 紧凑选择框 | 短枚举默认宽 160px，空间允许时最小 128px、最大 220px，不伸展填满行宽；空间不足先换行，极窄窗口或缩放时允许缩至容器内，完整选项仍可辨认。仅地址、长名称、正文等真实长内容输入使用填满宽度的字段。 |

| 折叠入口 | 共用 Disclosure，保留原生 details/summary 语义，移除默认 marker/字体三角；统一 1.5px SVG，顶级盒 12×12px，次级 10×10px，图标间距 8px。整项命中区至少 24×24px，次级行至少高 32px；展开只改变方向、不改变占位，Enter/Space 可操作且焦点可见。 |

状态文案归属具体对象和操作。常规保存成功不保留顶部提示，默认不显示空泛的「已同步」。设置页不常驻「正在陪你……」等正常活动叙事，也不重复显示已由开关、选中项或就地反馈表达的正常状态；当前活动由伙伴呈现。接收故障、保存失败、在途、授权警告和结果未确认仍在相关控件附近可读。收到过工具信号不代表当前在线，复制成功也不代表接入成功；名称、连接状态和操作回执不能互相替代。悬停可见的信息也须能通过聚焦或点击读取，不能仅依赖颜色或鼠标 title。

GSAP 用于弹层、页面的短促内容过渡及用户悬停、聚焦或点击时的图标反馈；页眉和按钮命中区域保持固定。换形态、换装、食物和旅程有各自的短动画，计时器没有持续呼吸光效。系统减少动效或产品低刺激设置关闭这些过渡。
同一图标尚在动画中时，悬停、聚焦和点击合并为一次反馈；点击只加快当前动画，不复位重播。回顾用书页、日常用叶片、待整理用分拣线、历史用时钟，各自具有对应的短动画。
能量以抗锯齿 SVG 曲线呈现，每个采样值保持不变，当前时间以后使用虚线；不把估算画成像素柱形。候选直接显示可点击行，说明在原位展开。
问号说明紧邻对应选项或小节，统一在顶层浮层中显示，不再另设引用式说明卡片。尺寸见上表；悬停、聚焦和点击均可阅读，支持移入浮层，Escape 只关闭当前说明。主题选中由单选圆点和底色表示，键盘焦点只在整项显示一道描边。二级弹窗保留外部边距、内部滚动和关闭出口；菜单只保留一层背景，行内以悬停和选中状态区分。量测与状态矩阵见 [VALIDATION「原生检查清单」](VALIDATION.md#原生检查清单)。

## 范围边界

生产档案须同时具有完整规范的schema19与BUBU品牌配置身份。无标记、其他品牌、不支持的旧版、损坏或孤立持久化档案拒绝打开且保留原件，不自动迁移、删除、重置或生成替代档案。唯一既有版本升级路径是完整有效的 BUBU18：启动确认框默认退出；本人勾选并确认后先建立完整私有备份，再只添加语言/主题默认值。取消不升级，备份失败不进入原库写入。升级后旧版不能直接打开19，恢复须关闭应用并显式解出到新目录。配置SQL1、奖励账本3、协作SQL4是不同版本命名空间；协作SQL1/2/3仅按已核验逐字节备份升级，不放开配置schema19的current-only要求。

- 桌面目标以 Windows/macOS 为主，构建入口另提供 Linux、x64 和 arm64；有构建入口不等于对应原生验收通过。签名、公证、Universal 和正式发布仍需单独验证。
- 没有内置本地模型、桌面内容识别、跨设备同步、账户系统或远程内容包下载；活动镜像只看前台应用与发声播放器的类别，不读内容。
- 不作临床疗效、情绪识别或自动决策承诺。
- 代码通过自动化不等于 macOS 视觉、输入设备和系统集成已通过；证据以 VALIDATION 为准。

时间线中不关联任务的会话称为“自由专注”；不足一分钟按秒显示，不四舍五入成 0 分。能量高低点直接标在估计曲线上，帮助说明只在问号内展开。

伙伴的受抚摸反馈应舒适愉悦；静态表情目录与实际输入链路分别验证，不用调试动作替代真实互动语义。
握持电脑等有朝向的物件时，以伙伴能合理使用为准，不能为向用户展示屏幕而让角色操作背面。

协作中的应用数据由用户逐类选择，默认只参考当前任务。任务、收件与普通日常的实际字段先展示；原文收件一律作为外部资料，不能扩大授权。待改项可编辑或取消，按新版本重新查看差异再确认。只有持久回执才标为已应用；时间线同步未完成时明确显示待同步，重复点击不会再次创建。撤销只在目标未被后续修改、且该操作可补偿时出现，仍须预览确认。回顾时间线分为专注、日常、收件与确认修改，可查看依据和回到对应对话；不展示聊天原文。

“AI记得什么”支持按原条目纠错、暂停、回收区恢复和单独永久移除。永久删除预览说明影响来源及不可撤销，不能删除已发送给外部服务的副本。确认一条记忆不会自动允许在聊天中使用；总开关与当次选择都要明确。

安排偏好、本机自评记录和曲线试用分别确认。历史默认关闭、不补录；不足10条或不足7天就显示依据不足。试用只是可撤销的日常安排估计，不是身体状态或医疗结论，不修改药物参数、不替代本人自评、不附带后台提醒。

协作对话可以建议新增记忆、纠正已选择并实际读取的记忆，或提出遗忘。纠正保持原ID并展示版本差异；遗忘进入单独的关联范围预览，需明确勾选永久移除确认。模型不能直接调用删除或用自己的确认标志授权。一个建议的真实回执在重开、撤销和恢复核对后仍对应同一身份，不重复执行。

## 应用内更新

设置内提供检查、下载、取消和重启安装。发现新版本不会自行下载或打断专注；专注/休息、待收口或无法确认数据已保存时不安装。
重启前明确提醒先保存尚未提交的输入。安装器保留用户数据目录，无需先卸载；这一目标仍须各原生平台签名包跨版本验收。
开发版明确提示尚不可用，不能把合成更新源测试说成真实Release已发布。

### 多语言预览边界（0.0.2-dev.1）

本分支首批支持简体中文与英文。跟随系统按系统偏好语言顺序选择已支持语言；中文变体暂回退简体中文，其他语言回退英文。文案目录只处理显式标注的产品文字，变量保留原文；任务、步骤、随手记、聊天、模型回复、用户命名和伙伴专有名称不自动翻译。原始错误详情保持实际字段/约束说明，不当作可翻译 UI 文案。

产品文案覆盖主导航、现在/专注/步骤、任务创建/编辑/完成/拆解、收件分拣与卡住流程、全部设置、安排/自评/回顾时间线、AI 会话与确认/撤销/记忆管理、快捷捕捉/执行，以及伙伴成长/衣橱/商店/食物与桌宠状态/命令。系统托盘和新生成的标准提醒标题、按钮与固定说明使用已确认语言；已发出的提醒正文不重新发送或改写。用户定制的日常标题、外部 Provider 详情与已有聊天/任务事实保持原文。

English 保持预览标记：伙伴信件/叙事、角色专有名称和本地 AI 内容模板保留原文，且 Windows/macOS 的双平台原生布局、辅助技术及系统外观切换仍须验收。切换语言不重写现有记录或 AI 提示词。已覆盖产品控件的语义状态也必须在切换后保留，包括确认前核对、保存未知、撤销核对和清理未确认，不能退回默认按钮文案。
